# Templates AEM Descontinuados do Vivo.Core.Pipelines

Os templates do **AEM** foram descontinuados do repositório `Vivo.Core.Pipelines`. Para acessar os templates atualizados, utilize o repositório **Vivo.CodePlay.Pipelines**.

## Informações Importantes

- **Novo local dos templates**: [Vivo.CodePlay.Pipelines](https://dev.azure.com/telefonica-vivo-brasil/DevOps/_git/Vivo.CodePlay.Pipelines?path=/tech_products/adbb-aem)

## Ações Necessárias

1. Atualize seus pipelines para referenciar o novo repositório: **Vivo.CodePlay.Pipelines**.
2. Caso tenha dúvidas de como fazer, entrar em contato com o time de DevOps B2B.

Para mais informações, consulte a documentação oficial em https://wikicorp.telefonica.com.br/x/Ei_ZGg ou entre em contato com o time de DevOps B2B.
